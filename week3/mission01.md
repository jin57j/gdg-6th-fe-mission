API 통신: 서버는 브라우저의 요청을 받아 데이터를 제공하는 서빙 역할을 하며, 프론트엔드와 백엔드는 데이터를 주고받는다 데이터 요청: 자바스크립트 내장 함수인 fetch를 사용하여 외부 서버 todo 데이터를 가져온다. 무한 루프 : 데이터를 받아와 상태(state)를 업데이트할 때, 컴포넌트가 재렌더링되면서 다시 요청을 보내는 무한 루프 문제가 발생할 수 있다. useEffect 사용: 외부 데이터와의 동기화를 위해 useEffect 훅을 사용하여 컴포넌트 생명 주기와 렌더링 과정을 분리한다 비동기 처리(Asynchronous): 서버 통신 시 응답을 기다리는 동안 화면이 멈추지 않도록 하기 위한 핵심 개념입니다. 코드가 순차적으로만 실행되지 않고, 특정 작업을 브라우저의 별도 기능에 맡긴 뒤 완료되면 처리하는 방식이다. 실제 구현: fetch 함수를 사용하여 데이터를 가져오고, response.json()을 통해 받은 문자열 데이터를 자바스크립트에서 활용 가능한 객체 형태로 변환하는 과정을 거친다.
