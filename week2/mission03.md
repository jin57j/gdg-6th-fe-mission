1. useState (상태 관리) 컴포넌트 내부에서 변화하는 데이터를 기억하고 관리하기 위해 사용합니다. 값이 변경되면 리액트가 이를 감지하고 화면을 자동으로 다시 그려줍니다.

핵심 역할: 컴포넌트의 기억 장치

활용 예시: 쇼핑몰 장바구니의 상품 수량 증감 버튼의 활성화 상태 (True/False)

2. useEffect (생명주기 및 사이드 이펙트) 컴포넌트가 화면에 나타날 때(Mount), 사라질 때(Unmount), 혹은 특정 값이 바뀔 때마다 특정 작업이 실행되도록 설정합니다.

핵심 역할: 외부 시스템(API, 타이머 등)과의 연결 및 동기화

활용 예시:

데이터 로딩: 페이지가 열리자마자 서버에서 공지사항 목록 가져오기

구독/해제: 브라우저 창 크기 조절 이벤트 등록 및 제거

업데이트 감지: 특정 변수가 바뀔 때마다 로그 남기거나 알림 띄우기

3. useNavigate (페이지 이동) react-router-dom 라이브러리에서 제공하는 기능으로, 사용자를 프로그래밍 방식으로 다른 URL로 이동시킬 때 사용합니다.

핵심 역할: 페이지 내비게이션 제어

활용 예시:

로그인 버튼을 눌렀을 때, 로그인이 성공하면 메인 페이지로 이동

글쓰기를 완료한 후 목록 페이지로 강제 이동

'뒤로 가기' 버튼 기능 구현

4. props과 state 그리고 hooks

잦은 DOM조작은 브라우저의 리소스를 많이 소모하고 성능을 저하-> Virtual DOM(가상 DOM) 이라는 개념을 도입. 변경 사항을 가벼운 가상의 DOM에서 먼저 처리한 후, 결과값만 모아서 실제 Real DOM에 한 번에 반영하여 성능을 극대화. useState (Hook): React가 상태(State) 변화를 감지하고 화면을 다시 리렌더링하기 위해 사용하는 기능 Props (Properties): 부모 컴포넌트가 가진 상태(State)나 데이터를 자식 컴포넌트에게 전달할 때 사용하는 속성값 부모 컴포넌트의 State가 변경되면, 해당 Props를 전달받은 자식 컴포넌트도 새롭게 렌더링 Mount (탄생): 컴포넌트가 화면에 처음 나타나는 단계. Update (변화): 새로운 Props를 받거나 State가 변경되어 화면이 리렌더링되는 단계. UnMount (죽음): 컴포넌트가 화면에서 완전히 제거되는 단계. 클래스형인 과거에는 디테일한 생애주기를 조절 가능했지만 학습 난이도가 높았고 함수형인 현재에는 코드가 간결해졌다.
