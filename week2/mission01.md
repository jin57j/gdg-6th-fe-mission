1. CSS 적용 방법 HTML 문서에 CSS를 적용하는 3가지 방법입니다.

External 외부 CSS 파일을 연결합니다. 가장 권장되는 방법입니다

Internal 태그를 사용하여 HTML 문서 안에 CSS를 작성합니다.

Inline HTML 태그 내부에 직접 style속성으로 작성합니다.

2. 셀렉터 HTML 요소를 선택하여 스타일을 지정하는 방식입니다.

기본 셀렉터

전체: 셀렉터 문서 내의 모든 요소를 선택합니다.

태그: 특정 HTML 태그를 모두 선택합니다.

ID: 특정 ID를 가진 단 하나의 요소를 선택합니다.

클래스: 셀렉터 특정 클래스를 가진 모든 요소를 선택합니다.

어트리뷰트: 특정 속성을 가진 요소를 선택합니다.

후손 셀렉터 (A B): A 요소 내부의 모든 B 요소를 선택합니다.

자식 셀렉터 (A > B): A 요소의 바로 아래 단계인 직계 자식 B 요소만 선택합니다.

가상 클래스 (:hover, :active, :nth-child 등): 요소의 특정 상태나 위치를 선택합니다.

3. 표현 단위 및 색상

px: 픽셀 고정된 크기를 가집니다.

rem: 최상위 요소(html)의 폰트 크기를 기준으로 합니다.

뷰포트 단위: 화면(브라우저 창) 크기를 기준으로 합니다.

색상 (Colors)

키워드 (red, blue), HEX 코드 (#FF0000) 등을 사용하여 표현합니다.

4. 박스 모델

Content : 텍스트나 이미지 등 실제 내용이 표시되는 영역입니다.

Padding : 콘텐츠와 테두리 사이의 안쪽 여백입니다.

Border : 요소의 테두리 선입니다.

Margin : 테두리 바깥쪽의 여백으로, 다른 요소와의 간격을 띄웁니다.

5. 디스플레이 및 표시 속성

display: 요소의 화면 출력 방식을 결정합니다.

block: 항상 새로운 줄에서 시작하며 가로 전체를 차지합니다.

inline: 줄 바꿈 없이 내용의 크기만큼만 차지합니다.

inline-block: 줄 바꿈은 없지만 너비/높이를 지정할 수 있습니다.

none: 화면에서 완전히 사라지며 공간도 차지하지 않습니다.

visible: 보임.

hidden: 화면에서 보이지 않지만, 원래 있던 공간은 그대로 차지합니다.

opacity: 요소의 투명도를 조절합니다.

6. 텍스트 프로퍼티

font-size: 글자 크기.

font-weight: 글자 굵기

letter-spacing: 글자 사이의 간격.

line-height: 줄 간격.

text-align: 텍스트 정렬

color: 글자 색상.

7. 위치 프로퍼티 및 정렬

static: 기본값. 문서의 일반적인 흐름에 따라 배치됩니다.

relative: static을 기준으로 이동합니다.

absolute: static이 아닌 가장 가까운 부모 요소를 기준으로 절대적인 위치에 배치됩니다.

fixed: 화면을 기준으로 고정 배치되어 스크롤해도 움직이지 않습니다.

sticky: 스크롤 전에는 relative처럼 동작하다가 특정 위치에 도달하면 fixed처럼 고정됩니다.

정렬 속성

float: left: 요소를 왼쪽으로 띄웁니다.

float: right: 요소를 오른쪽으로 띄웁니다.

일반 css 의 경우 는 전역 모든 곳에 영향이고 module.css는 지역 해당 컴포넌트에만 영향을 준다 적용 방식에도 차이가 있는데 css는 className="btn" 이고 module의 경우 className={styles.btn} 로 객체 처럼 사용한다. 이는 특히 여러 css 파일을 임포트할때 유용하다 모듈의 경우 객체처럼 사용할 수 있어 같은 이름을 가진 요소가 있더라도 충돌없이 구분지어 사용할 수 있다.
