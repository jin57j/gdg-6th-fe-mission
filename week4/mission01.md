1. 리팩토링이란? 기능의 변경 없이 코드의 구조를 재조정하는 작업을 의미한다. 코드를 처음부터 완벽하게 짜기는 어렵기 때문에 개발 과정에서 지속적으로 구조를 다듬어 더 좋은 코드로 발전시키는 과정이다.
2. 컴포넌트화 (파일 분리) App.js에 모든 로직을 몰아넣는 대신 관심사에 따라 코드를 나누어야한다.
3. 프롭스(Props) 활용 부모 컴포넌트(App.js)에서 자식 컴포넌트(Todo.js)로 데이터를 전달할 때 (Props)를 사용한다 App.js에서 각 데이터를 넘겨줌으로써, 자식 컴포넌트가 재사용 가능한 독립적인 부품처럼 작동하게 한다

커스텀 훅(Custom Hook)은 리액트 개발 시 중복되는 로직을 재사용 가능한 함수로 묶어 관리하는 개념이다.

1. 커스텀 훅이 필요한 이유 여러 컴포넌트에서 동일한 로직(예: useState, useEffect, fetch 등을 활용한 데이터 통신)이 반복될 때, 이를 매번 작성하는 것은 비효율적이다. 커스텀 훅을 사용하면 이러한 로직을 하나의 함수로 추상화하여, 컴포넌트 내부에서는 필요한 데이터만 간결하게 호출해서 사용할 수 있게 된다. 컴포넌트 안에서는 복잡한 useEffect나 fetch 로직을 신경 쓸 필요 없이, 커스텀 훅을 통해 결과값을 바로 받아올 수 있어 간결하다는 장점이 있다. 남용하기보다는 상황에 맞게 필요한 경우에만 효율적으로 사용해야 한다.
