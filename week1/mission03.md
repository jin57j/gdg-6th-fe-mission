DOM은 HTML 태그 하나하나를 자바스크립트로 컨트롤할 수 있도록 만든 트리 구조의 객체 체계입니다. 기존 방식은 순수 HTML과 JS만으로 여러 명의 개발자가 대규모 코드를 작업하면 코드가 섞이고 유지보수 비용이 기하급수적으로 늘어나는 한계가 있었지만, React를 사용하여 이를 해결할 수 있습니다.

JSX는 JS 코드 안에 HTML을 직접 작성하여 화면을 컴포넌트 단위로 나누어 개발할 수 있게 해주는 문법입니다. UI 요소와 자바스크립트 작동 로직을 한 파일에서 직관적으로 관리할 수 있게 해주는 핵심적인 역할을 합니다.

SPA (Single Page Application)는 페이지 새로고침 없이도 한 페이지가 하나의 앱처럼 부드럽게 동작하게 만드는 웹 애플리케이션 형태입니다. React를 통해 매번 새로운 페이지를 통째로 불러오지 않고 필요한 부분만 업데이트하여 부드러운 사용자 경험을 제공합니다.

리액트 실행방법은 터미널을 통해 프로젝트를 생성하고 구동하는 과정입니다. 예를 들어 npx create-react-app 을 입력해 프로젝트를 생성한 후, cd 로 폴더에 진입하고 npm start로 로컬 서버를 실행하여 작업 중인 화면을 브라우저에 띄울 수 있습니다.
