HTML5 HTML5는 웹 페이지의 뼈대를 구성하는 마크업 언어(HTML)의 가장 최신 표준 규격입니다. 기존과 달리 문서 구조의 의미를 명확히 하는 시맨틱 태그가 도입되었으며, 별도의 플러그인없이도 비디오나 오디오 같은 멀티미디어를 웹 브라우저에서 자체적으로 바로 재생할 수 있게 해줍니다

요소는 웹 페이지를 구성하는 가장 기본적인 블록입니다. 일반적으로 <> 내용</>의 전체 형태를 하나의 요소라고 부릅니다. 예를 들어 <p>안녕하세요</p> 전체가 하나의 요소에 해당합니다.

어트리뷰트는 요소에 추가적인 정보나 세부 설정을 부여할 때 사용합니다. 항상 '여는 태그' 내부에 작성하며, 속성이름=값의 형태를 가집니다. 예를 들어<img src="profile.png">에서 이미지를 불러오는 src가 속성입니다. JS로 화면을 조작할 때 요소를 식별하는 id 역시 중요한 속성 중 하나입니다.

시멘틱 요소는 태그의 이름만으로도 그 안의 내용이 어떤 의미인지 명확하게 알 수 있는 요소입니다.단순 영역 나누기용인 <div>의 무분별한 사용을 방지합니다. 검색 엔진 최적화(SEO)와 시각 장애인을 위한 스크린 리더 등 웹 접근성을 크게 향상시킵니다.

태그들은 브라우저 화면에서 공간을 차지하는 방식에 따라 크게 두 가지로 나뉘며, 이는 추후 CSS 레이아웃을 잡을 때 매우 중요합니다. 블록 레벨 태그는 요소가 항상 새로운 줄에서 시작하며, 부모 요소의 가로 너비 100%를 모두 차지합니다.예를 들어 <div>, <p>, <h1> ~ <h6>가 있습니다. 인라인 레벨 태그는 내용의 크기만큼만 공간을 차지하며, 줄바꿈 없이 옆으로 나란히 이어집니다.예를 들어 <span>, <a>, <img> 가있습니다

하이퍼링크는 사용자가 클릭했을 때 다른 웹 페이지, 파일, 또는 현재 문서의 다른 위치로 이동할 수 있게 해주는 기능입니다. 닻을 뜻하는 <a> (Anchor) 태그를 사용합니다. 목적지를 알려주기 위해 반드시 href 어트리뷰트를 함께 써야 합니다. 예를 들어 <a href="https://www.google.com"></a>로 표현 할수있습니다.

js 자바스크립트(JS)는 웹 페이지를 동적으로 만들고 사용자와 상호작용할 수 있게 해주는 프로그래밍 언어입니다.예를 들어 버튼을 클릭했을 때 숫자가 증가하게 하거나, 새로운 팝업창을 띄우는 기능을 구현할 때 사용합니다.

변수는 데이터를 저장하기 위해 할당받은 메모리 공간에 붙인 이름입니다. 프로그램이 실행되는 동안 값이 변할 수 있는 데이터를 담아두는 상자 역할을 합니다. 예를 들어 let age = 20;에서 데이터를 저장하는 공간의 이름인 age가 변수에 해당합니다.

var는 자바스크립트에서 변수를 선언할 때 사용하는 전통적인 키워드입니다. 하지만 코드 블록을 무시하는 등 여러 단점이 있어, 현재는 이를 보완한 let과 const의 사용이 권장되며 잘 쓰이지 않습니다. 예를 들어 var name = "GDG";처럼 변수 이름 앞에 작성하여 변수를 생성할 수 있습니다.

데이터타입은 프로그래밍에서 다루는 값의 종류를 의미합니다. 자바스크립트에는 Number, String, Boolean 같은 원시 Object 타입이 존재합니다.

문(Statement)은 프로그램을 구성하는 기본 단위이자 컴퓨터에게 내리는 최소한의 실행 명령입니다. 여러 개의 단어와 기호로 구성되며, 컴퓨터는 이 문들을 위에서 아래로 순서대로 읽고 실행합니다. 예를 들어 변수를 선언하는 let x = 10; 한 줄 전체나, 조건을 판단하는 if문 블록 전체가 각각 하나의 문에 해당합니다.

조건문은 주어진 조건식의 참(true)과 거짓(false) 결과에 따라 실행할 코드를 결정하는 제어문입니다. 상황에 따라 프로그램의 실행 흐름을 다르게 나눌 때 필수적으로 사용됩니다. 예를 들어 if (score >= 80) { console.log("합격"); }의 형식을 가집니다

반복문은 특정 조건이 참인 동안 동일한 코드 블록을 계속해서 반복 실행하는 제어문입니다. 똑같은 작업을 여러 번 효율적으로 처리해야 할 때 사용합니다. 예를 들어 for (let i = 0; i < 5; i++) { }의 형식을 가집니다

함수 객체는 일련의 과정을 문으로 구현하고 코드 블록으로 감싸서 하나의 실행 단위로 묶어둔 것입니다. 자바스크립트에서 함수는 값으로 취급되는 객체이므로, 변수에 담거나 다른 함수의 전달인자로 사용할 수 있습니다. 예를 들어 function add(a, b) { return a + b; } 전체가 하나의 함수 객체이며, 필요할 때마다 add(1, 2)처럼 호출하여 코드를 재사용할 수 있습니다.
